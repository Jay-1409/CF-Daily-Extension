Install in under a minute.

CF-Daily is distributed as an unpacked extension. Download the ZIP, extract it, and point your Chromium browser at the folder.

Download ZIP ↓
  1. Extract the ZIP
    Open the downloaded archive and extract the CF-Daily folder.
  2. Open your extensions page
    Visit chrome://extensions and enable Developer mode.
  3. Choose Load unpacked
    Select the extracted CF-Daily folder. Pin the extension and start solving.
